# Каталог вариантов дизайна goldmercury93.ru

Рабочий каталог вариантов первого экрана для редизайна сайта регионального конкурса «Золотой Меркурий» (ТПП Краснодарского края). Не для индексации.

- `index.html` — каталог, читает `variants.json`.
- `v/<NN-slug>/index.html` — вариант; `?s=closed` показывает состояние «вне сезона».
- `shots/` — скриншоты 1440×900 и 390×844 для каталога: `npm i`, затем `node tools/shot.mjs [slug ...]` при запущенном локальном сервере на порту 8770.
- `assets/` — фото с церемоний (архив новостей сайта), знак премии, шрифты (OFL, Google Fonts).

Добавить вариант: папка в `v/`, строка в `variants.json`, `node tools/shot.mjs <slug>`, коммит.
